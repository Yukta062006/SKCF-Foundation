# 🌱 SK Children Foundation - Digital Experience

A modern, responsive and human-centered website designed for **SK Children Foundation (SKCF)** as part of a Web Developer assignment.

The website presents SKCF's mission, activities and community work through a clean, engaging and accessible digital experience.

##  Features

-  Modern and clean UI/UX
-  Fully responsive design
-  Smooth scroll and entrance animations
-  Interactive activity sections
-  Local SKCF image assets
-  Accessibility-focused design
-  Performance-conscious frontend
-  Mobile-friendly navigation

##  Getting Started

### Clone the repository

```bash
git clone https://github.com/Yukta062006/SKCF-Foundation.git
```

### Install dependencies

```bash
cd SKCF-Foundation
npm install
```

### Run the development server

```bash
npm run dev
```

Open the website at:

http://localhost:5173

##  Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
